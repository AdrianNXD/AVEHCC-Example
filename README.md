This repo features examples to be used with the [AVEHCC](https://huggingface.co/datasets/AdrianNowak/AVEHCC) dataset (Acoustic VEHicle Counting and Classification). The Notebook *Vehicle_Counting_Example.ipynb* demonstrates training and validating a MobileNet V3 large as a acoustic based vehicle counting model. 

The script *Chunk_Generator* can be used to create audio chunks specifically using the AVEHCC dataset and *Audio_To_Mel* creates mel-spectrograms with fixed target resolutions.
